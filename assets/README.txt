ASSET PLACEMENT INSTRUCTIONS
============================

Place your two image files in this folder:

  portrait.jpg   — The portrait painting image
                   (the painting to be revealed on the easel)

  logo.png       — The Kathleen McGinn signature/logo image
                   (transparent PNG preferred for best blending)

File references in index.html:
  ./assets/portrait.jpg
  ./assets/logo.png

To change filenames: update the src= attributes in index.html, lines ~37 and ~55.
